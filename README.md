# 一人麻雀道場

AI3人と四人麻雀を打ち、**自分の打牌を1手ずつ採点して「何がダメだったか」を指摘する**練習アプリ。
ブラウザだけで動く（サーバー・ビルド不要）。

## できること

**対局**
- 東風戦 / 半荘 / 1局のみ
- リーチ・ポン・チー・カン（暗槓/明槓/加槓）・ツモ・ロン
- 赤ドラ3枚、裏ドラ、一発、ダブリー、槍槓、嶺上開花、海底/河底
- フリテン（通常・同巡・リーチ後）、九種九牌、流局時のテンパイ料、本場・供託・連荘
- 符計算と役判定（平和〜国士無双・四暗刻・九蓮宝燈まで。数え役満・複合役満あり）

**検討（このアプリの主目的）**
- 打牌ごとに全候補のシャンテン数と受け入れ枚数を計算し、選んだ牌と最善手を比較
- 即時指摘: 1手打つたびに「◎最適 / △受け入れ○枚ロス / ✗シャンテン戻し」を表示
- 押し引き判定: 他家のリーチに対する危険度（現物・筋・字牌の残り枚数）と自分の向聴数から、
  ベタオリすべき局面での押しを検出
- 和了見逃し、リーチ判断、鳴き判断、放銃（回避可能だったか）も記録
- 終局後レポート: 最適打率・平均受け入れロス・ミス一覧（その局面の手牌つき）・総評

**練習補助**
- アシスト表示: 現在の向聴数、推奨打牌、受け入れ枚数と内訳、安全牌（🛡）/危険牌（危）マーク
- どちらもワンタップでオフにでき、本番同様の条件でも打てる

## 使い方

ブラウザで `local.html` を開く。相対パスで JS/CSS を読むため、ローカルでは簡易サーバー経由が確実：

```bash
python3 -m http.server 8000
# → http://localhost:8000/local.html
```

`index.html` は Claude Artifact 用（`<!doctype>`/`<head>` を持たない形式）。中身は `local.html` と同じ構成。

## 構成

```
index.html      Artifact 用エントリ
local.html      ローカル閲覧用エントリ（内容は同じ）
style.css       スタイル（ライト=白木の卓 / ダーク=緑の羅紗、牌はCSS描画）
ui.js           卓の描画・操作・検討レポート画面
src/core.js     牌の表現、シャンテン数、受け入れ計算、和了形の分解
src/score.js    役判定・符計算・点数計算
src/game.js     対局進行（UI非依存の async ステートマシン）
src/ai.js       AI（牌効率＋押し引き）
src/review.js   検討エンジン（1手ごとの採点とミス検出）
tests/          エンジンの検証テスト
```

### シャンテン数の計算について
スート単位の分解表をメモ化し、4グループ（萬/筒/索/字）をDPで合成する方式。
1局面あたり約7µs で、総当たりのリファレンス実装と乱数16000局面で一致を確認済み。

## テスト

```bash
node tests/engine.test.cjs    # 45件: シャンテン/待ち/受け入れ/役/符/点数
```

`tests/sim.cjs` は AI 同士で多数対局を回し、例外が出ないこと・点棒の合計が常に
100000 に保たれること（供託込み）を確認する。

```bash
node tests/sim.cjs
```
